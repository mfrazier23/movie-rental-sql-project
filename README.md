# 🎬 Movie Rental Database Management System

## Overview

This project demonstrates the design and implementation of a relational database for a movie rental business using Oracle SQL. The database models real-world rental operations, including customers, movies, inventory, rentals, distributors, actors, directors, genres, and awards.

The project showcases database design, SQL development, and data management skills through the creation of tables, data insertion, complex queries, and transaction management.

---

## Objectives

- Design a normalized relational database
- Create relational tables
- Populate the database with sample data
- Retrieve business information using SQL queries
- Perform CRUD operations
- Demonstrate transaction management using COMMIT and ROLLBACK
